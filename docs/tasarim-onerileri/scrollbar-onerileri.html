Kaydırma Çubuğu Önerileri

Ravencia — Sade teması için 10 özel kaydırma çubuğu. Her kutuyu kaydırıp üzerine gelerek deneyin; CSS doğrudan kopyalanabilir.

1 · Mac İnce

İnce, yuvarlak ve şeffaf raylı; macOS hissine en yakın, en az dikkat çeken seçenek.

.sb-1 { scrollbar-width: thin; scrollbar-color: #4a4a55 transparent; }
.sb-1::-webkit-scrollbar { width: 8px; height: 8px; }
.sb-1::-webkit-scrollbar-track { background: transparent; }
.sb-1::-webkit-scrollbar-thumb { background: #4a4a55; border-radius: 8px;
  border: 2px solid transparent; background-clip: padding-box; }
.sb-1::-webkit-scrollbar-thumb:hover { background-color: #5c5c69; }
.sb-1::-webkit-scrollbar-corner { background: transparent; }

2 · Mor Vurgulu

Normalde nötr gri; üzerine gelince marka moruna döner.

.sb-2 { scrollbar-width: thin; scrollbar-color: #383842 #17171c; }
.sb-2::-webkit-scrollbar { width: 10px; height: 10px; }
.sb-2::-webkit-scrollbar-track { background: #17171c; }
.sb-2::-webkit-scrollbar-thumb { background: #383842; border-radius: 6px; }
.sb-2::-webkit-scrollbar-thumb:hover { background: #8b5cf6; }
.sb-2::-webkit-scrollbar-corner { background: #17171c; }

3 · Gizlenen (hover'da görünen)

Thumb yalnızca kutunun üzerine gelince görünür; yer kaplar ama göze girmez.

.sb-3 { scrollbar-width: thin; scrollbar-color: transparent transparent; }
.sb-3:hover, .sb-3:focus-within { scrollbar-color: #4a4a55 transparent; }
.sb-3::-webkit-scrollbar { width: 8px; height: 8px; }
.sb-3::-webkit-scrollbar-track { background: transparent; }
.sb-3::-webkit-scrollbar-thumb { background: transparent; border-radius: 8px; }
.sb-3:hover::-webkit-scrollbar-thumb { background: #4a4a55; }
.sb-3::-webkit-scrollbar-thumb:hover { background: #5c5c69 !important; }
.sb-3::-webkit-scrollbar-corner { background: transparent; }

4 · Kapsül Raylı

Ray da thumb da kapsül biçiminde; ray kenardan içeri çekilmiş, hafif yüzer görünür.

.sb-4 { scrollbar-width: thin; scrollbar-color: #55556a #22222a; }
.sb-4::-webkit-scrollbar { width: 12px; height: 12px; }
.sb-4::-webkit-scrollbar-track { background: #22222a; border-radius: 999px;
  border: 3px solid #1d1d23; }
.sb-4::-webkit-scrollbar-thumb { background: #55556a; border-radius: 999px;
  border: 3px solid #1d1d23; }
.sb-4::-webkit-scrollbar-thumb:hover { background: #6a6a80; }
.sb-4::-webkit-scrollbar-corner { background: #1d1d23; }

5 · Kenar Çizgili

Rayı içerikten 1px çizgiyle ayırır; tablo ve paneller için düzenli, köşeli görünüm.

.sb-5 { scrollbar-width: thin; scrollbar-color: #383842 #17171c; }
.sb-5::-webkit-scrollbar { width: 10px; height: 10px; }
.sb-5::-webkit-scrollbar-track { background: #17171c; border-left: 1px solid #2a2a32; }
.sb-5::-webkit-scrollbar-track:horizontal { border-left: 0; border-top: 1px solid #2a2a32; }
.sb-5::-webkit-scrollbar-thumb { background: #383842; border-radius: 0;
  border: 2px solid #17171c; }
.sb-5::-webkit-scrollbar-thumb:hover { background: #6f6f7c; }
.sb-5::-webkit-scrollbar-corner { background: #17171c; }

6 · Geniş Dokunmatik

14px genişlik ve en az 40px thumb; tablet ve dokunmatik ekranda kolay yakalanır.

.sb-6 { scrollbar-width: auto; scrollbar-color: #4a4a55 #17171c; }
.sb-6::-webkit-scrollbar { width: 14px; height: 14px; }
.sb-6::-webkit-scrollbar-track { background: #17171c; }
.sb-6::-webkit-scrollbar-thumb { background: #4a4a55; border-radius: 10px;
  border: 3px solid #17171c; min-height: 40px; }
.sb-6::-webkit-scrollbar-thumb:hover { background: #5c5c69; }
.sb-6::-webkit-scrollbar-corner { background: #17171c; }

7 · Sade Mor Thumb

Degrade yok; soluk mor ray üzerinde düz mor thumb, hover'da tam marka rengi.

.sb-7 { scrollbar-width: thin; scrollbar-color: #5b45a0 #272139; }
.sb-7::-webkit-scrollbar { width: 8px; height: 8px; }
.sb-7::-webkit-scrollbar-track { background: #272139; }
.sb-7::-webkit-scrollbar-thumb { background: #5b45a0; border-radius: 8px; }
.sb-7::-webkit-scrollbar-thumb:hover { background: #8b5cf6; }
.sb-7::-webkit-scrollbar-corner { background: #272139; }

8 · Çerçeveli Thumb (padding-box)

Şeffaf kenarlık + padding-box ile içeri çekilmiş, ince çerçeveli thumb.

.sb-8 { scrollbar-width: thin; scrollbar-color: #22222a #1d1d23; }
.sb-8::-webkit-scrollbar { width: 12px; height: 12px; }
.sb-8::-webkit-scrollbar-track { background: #1d1d23; }
.sb-8::-webkit-scrollbar-thumb { background: #22222a padding-box;
  border: 3px solid transparent; border-radius: 999px;
  box-shadow: inset 0 0 0 1px #383842; }
.sb-8::-webkit-scrollbar-thumb:hover { background-color: #2c2c36;
  box-shadow: inset 0 0 0 1px #6f6f7c; }
.sb-8::-webkit-scrollbar-corner { background: #1d1d23; }

9 · Overlay / scrollbar-gutter stable

Yarı saydam thumb, şeffaf ray; gutter sabit olduğu için içerik kaymaz.

.sb-9 { scrollbar-gutter: stable; scrollbar-width: thin;
  scrollbar-color: #3f3f4a transparent; }
.sb-9::-webkit-scrollbar { width: 10px; height: 10px; background: transparent; }
.sb-9::-webkit-scrollbar-track { background: transparent; }
.sb-9::-webkit-scrollbar-thumb { background: rgba(163,163,176,.22);
  border-radius: 999px; border: 3px solid transparent; background-clip: padding-box; }
.sb-9::-webkit-scrollbar-thumb:hover { background-color: rgba(163,163,176,.38); }
.sb-9::-webkit-scrollbar-corner { background: transparent; }

10 · Minimal 3px

Neredeyse görünmez 3px çizgi; yan menü ve dar listeler için.

.sb-10 { scrollbar-width: thin; scrollbar-color: #383842 transparent; }
.sb-10::-webkit-scrollbar { width: 3px; height: 3px; }
.sb-10::-webkit-scrollbar-track { background: transparent; }
.sb-10::-webkit-scrollbar-thumb { background: #383842; border-radius: 3px; }
.sb-10::-webkit-scrollbar-thumb:hover { background: #8b5cf6; }
.sb-10::-webkit-scrollbar-corner { background: transparent; }
